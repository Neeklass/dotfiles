# MinimalGlass for Rainmeter

## Installation

1. Extract the ZIP archive.
2. Run `install-minimalglass.ps1` with PowerShell.
3. In Rainmeter, select `Refresh all`.
4. Select `Manage -> MinimalGlass -> MinimalGlass.ini -> Load`.
5. Position the widget in the bottom-right corner.

Alternatively, copy `MinimalGlass.ini` directly to
`%USERPROFILE%\Documents\Rainmeter\Skins\MinimalGlass\MinimalGlass.ini`.

## Position

- About 16–20 px from the right edge.
- About 70–80 px above the taskbar.
- Turn `Draggable` off after positioning the widget.
- Turn `Keep on screen` and `Save position` on.

## Glass

The skin is semi-transparent even without an additional plugin.
The `FrostBehind` plugin provides the acrylic blur effect.
