# Wallpapers

A place for desktop backgrounds I use. No images are included yet.

Add images directly to this folder; introduce subfolders only if the
collection grows enough to need them.

- Use descriptive lowercase names with hyphens, such as
  `misty-hills-3840x2160.jpg`.
- Keep a useful desktop resolution, usually 2560x1440 or 3840x2160, or the
  image's original dimensions if smaller. Avoid upscaling and duplicate sizes.
- Prefer JPEG for photographs and PNG for artwork that needs lossless detail.
  Aim for a few megabytes per image and avoid committing large source files.
- Remove private metadata, including GPS location, before committing.
- Add only your own work or images whose terms allow redistribution. If
  redistribution is unclear, link to the creator's original page instead.

For each addition, record the filename, title, creator, original source URL,
license or permission, and any edits in this README. Preserve any attribution
or license notice the creator requires. Choose explicit reuse terms for your
own images; a future code license should not automatically cover wallpapers.
